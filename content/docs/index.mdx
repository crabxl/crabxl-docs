---
title: CrabXL
description: Read, write and edit XLSX files with a Rust core.
---

CrabXL is a library for XLSX files. It reads, writes and edits workbooks. The
Rust core does the work. Each language package uses the same core.

CrabXL is alpha software. An unsupported feature gives an explicit error. It
does not drop data. CrabXL does not calculate formulas.
